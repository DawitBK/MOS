# MOS documents

The folders are numbered in reading order: from the big picture down to the details, then meetings and inputs. **Bold** marks the current document; plain text marks one kept as history.

**In a browser, use the [start page](../index.html) instead.**

## [1. Overview](1-overview/)

Start here: the whole package on one page.

- **[Master plan](1-overview/MOS-MASTER-PLAN.html)**: Everything on a few pages: the six-month plan, team options, decisions, architecture, risks. *v0.5, 3 Oct*

## [2. Requirements](2-requirements/)

What the system must do, and who does what in which order.

- **[Requirements (FRD)](2-requirements/MOS-FRD.html)**: What the system must do: 231 numbered requirements, business rules, controls, acceptance scenarios. *v0.3.5, 3 Oct*
- **[Process model](2-requirements/MOS-PROCESS-MODEL.html)**: Who does what, step by step: the value chain, the whole-ERP flow, 21 swimlanes, lifecycles, exceptions, RACI. *v0.2, 27 Sep*

## [3. Design](3-design/)

Where the data lives and how the system is built.

- **[Database design](3-design/MOS-DATABASE-DESIGN.html)**: Where the data lives: 230 tables in 9 groups, every column, diagrams and worked examples. *v0.1.1, 28 Sep*
- **[Technical design (TDD)](3-design/MOS-TDD.html)**: How it will be built: architecture, stock ledger, security, deployment options. *v0.3.3*

## [4. Plan](4-plan/)

How much work, in what order, and by when.

- **[Implementation plan](4-plan/MOS-IMPLEMENTATION-PLAN.html)**: Everything in 26 weeks: the estimate (2,439 core hours), the speed each team needs, the roadmap, go-live W24, risks. *v0.5, 3 Oct*
- **[Sprint plan](4-plan/MOS-SPRINT-PLAN.html)**: 13 two-week sprints, feature by feature: tasks, "done when" tests, client inputs, rolling UAT, go-live sprints. *v0.2, 3 Oct*
- **[Module 1 plan (procurement)](4-plan/MOS-PROCUREMENT-MODULE-PLAN.html)**: The first module in detail: 54 stories, week plans, UAT script, data migration, training. *v0.2, 3 Oct*

## [5. For the client](5-for-the-client/)

- **[Commercial proposal](5-for-the-client/MOS-COMMERCIAL-PROPOSAL.html)**: What it costs: one fixed price, packages, maintenance, payment schedule, terms. *v0.4 draft, not sent*
- **[Pricing and timeline](5-for-the-client/MOS-PRICING-AND-TIMELINE.html)**: The fixed price (ETB 986,615, within ETB 1,000,000) by phase, sprint, module and feature, with the payment schedule. *v0.1 draft, not sent*
- **[Stakeholder questionnaire](5-for-the-client/MOS-STAKEHOLDER-QUESTIONNAIRE.html)**: The questions for the client, with answer fields and the week each answer is needed by. *v0.2 draft, not sent*

## [6. Decisions](6-decisions/)

What is decided, what is open, and why.
