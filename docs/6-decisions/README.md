**Formats:** "page" is the browser view, and "text" is the `.md` master copy (preview it in VS Code with Ctrl+Shift+V).

A new decision gets a new numbered ADR in `adr/` plus a row in the register. Old ADRs are never deleted; a replaced one is marked "Superseded".
