How to read these files

  • Open page opens the browser view. It works offline, except that diagrams in the bigger pages need internet to draw.
  • Text (.md) is the master copy. In a browser it shows as plain text, so read it in VS Code (Ctrl+Shift+V previews it) or on GitHub.
  • Faded cards are history, kept because later documents cite them.
  • Everything stays on this machine and in the private repository. Nothing is published online.
